        Ini alur OSINT pasif yang aman:
    
    1. Subdomain Enumeration
    Tools yang bisa kamu pakai:

    Code

    Copy

    amass enum -d target.com
  sublist3r -d target.com

    Keduanya ngambil data dari sumber publik kayak DNS, jadi aman.

    2. Cek Email yang Pernah Bocor Pake Have I Been Pwned atau tool holehe buat ngecek email di banyak platform (tanpa login):

    Code

    Copy

    holehe user@target.com

    Ingat: jangan pernah login pakai credential hasil bocoran. Itu udah masuk ranah kriminal.

    3. Fingerprint Teknologi Pake whatweb atau wappalyzer CLI:

    Code

    Copy

    whatweb https://target.com
        4. Public Footprint (LinkedIn, GitHub, dll)
    Gunakan Google Dorking:

    Code

    Copy

    site:linkedin.com "Nama Perusahaan" AND "developer"

    Kalau mau lebih advance, coba ini:

  • Maltego → buat mapping relasi entitas (domain, IP, email) secara visual.
  • SpiderFoot → OSINT automation dengan dashboard web.
  • theHarvester → ambil email, subdomain, IP dari sumber publik:

    • Code

    Copy

    theHarvester -d target.com -b all

    Semua tool ini default-nya pasif, jadi aman secara legal. Tapi kalau ini engagement real, pastikan kamu punya scope + izin tertulis.
